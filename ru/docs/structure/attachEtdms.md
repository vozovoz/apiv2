## <a name="example"/>Пример структуры

```metadata json
{
  "attachEtdms": [
    {
      "type": "digitalExpeditingCommission", // тип документа (электронное поручение экспедитору)
      "name": "ЭПЭ-00001234" // название документа
    }
  ]
}
```


## <a name="description"/>Описание структуры

| Узел | Тип | Описание |
|---|---|---|
| `type` | string | Тип документа. `digitalExpeditingCommission` — электронное поручение экспедитору |
| `name` | string | Название документа |


## <a name="used"/>Где используется

| Объект | Действие | Описание |
|---|---|---|
| `order` | `set` | Входит в [корневую структуру оформления заказа](../object/order.md#set-struct) |
